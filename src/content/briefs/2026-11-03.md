## TL;DR

- torch 2.15.0 is GA (28 Oct). The build we measured on 23 Oct was a different commit from GA. I
  re-ran the linalg.inv repro on the verified GA wheel and it is fixed at every size. The upgrade
  decision point can now use GA.
- M1 batch 02 is about one-third done: 12 templates prepared, 8 of 23 jobs judged. SeedVR2 int8
  upscale passes. MoGe panorama-to-mesh segfaulted ComfyUI. Video utility templates are too slow at
  their default settings. The Wan 2.1 jobs did not run yet.
- `agent-directed` First research plan drafted. M0 is four local checks plus one
  3-shot run. slopcore's five films show soundtrack-based lip-sync checks passing a video that viewers
  rejected.

## Research: what's new

- `unity-comfy` torch 2.15.0 is on PyPI with macOS arm64 wheels. MPS now needs macOS 15+; this Mac
  is on 26.5.1.
- `unity-comfy` Releases:
  - comfy-cli 1.25.0 adds `--output-node-ids`, which skips preview nodes.
  - comfy-agent 0.1.0rc7 is public on PyPI. It may need the network or an account; unknown, so it
    is a trial only.
  - Templates 0.11.100 add partner-API templates only.
  - ComfyUI core is unchanged (0.43.0). The LTX MPS fix PR is still unmerged.
- `unity-comfy` Well-Typed ComfyUI (arXiv 2610.37673): 32% of composition failures are silent and
  pass ComfyUI's validator. That supports a small pre-run compatibility rule set in V1/E2.
- `agent-directed` VibeVideoBench: judges rank systems well (ρ 0.98) but single videos poorly (r 0.44–0.50).
- `agent-directed` PVSync, a mouth-based lip-sync metric, tracks humans at ρ 0.83 vs 0.34 for LSE-C. Code unreleased.
- `agent-directed` Drafting at 480p and finalizing once is the main cost lever: about $1,200 for 13 min across four films.

## Risks / blocked

- An unattended batch has no supervisor. If a template crashes ComfyUI, every job after it waits
  for its deadline. I restarted ComfyUI by hand this run. A restart supervisor is next.
- Two "Visual Studio" helper processes have been at about 150% CPU each since 22 Oct. They are
  slowing every measurement. I didn't touch them.
- Batch-02 timings were measured on that busy machine.
