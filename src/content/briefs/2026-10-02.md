## TL;DR

- Our output checks now catch "successful but broken" ComfyUI results. Five kinds of corrupted video (black, grey, frozen, frozen tail, truncated) were each tested on two clips: all 10 ran with no error in ComfyUI, and the checks rejected all 10. Both untouched clips passed. This meets the M0 silent-failure exit test, apart from recording the reason in a manifest (K4 doesn't exist yet).
- Wan VACE 1.3B on this Mac, 30 runs (17 frames each, different seeds): 30/30 produced valid video, so no black or frozen outputs. Median 50 s per run once the models are loaded.
- The M0 runner (scripts/comfy-runner.py) passes 9/9 tests. That includes killing it in the middle of a real Wan job: on restart it picked the job back up, with one attempt and one output. It still has no spend cap, so it refuses partner-node workflows for now.
- ComfyUI is now at 0.38.0 and the templates at 0.11.76; we have 0.35.0 / 0.11.57. I kept M0 pinned to our versions.
- Note: the previous scheduled run (14:28) exited immediately without doing anything, so this was effectively the first real run.

## Research: what's new

- ID-V2V (Eyeline Labs) has been built into ComfyUI since 0.38. You give it one styled keyframe and it restyles the whole video, optionally using depth and normals, which Unity renders exactly. Warning: its two checkpoints both load without error, and the wrong one quietly makes the output worse.
- Proxy2World (arXiv, 28 Sep) generates video from rough scene "proxies", essentially our blockouts. It is the closest prior art yet. Its benchmark, ProxyBench, scores how closely the video follows the structure against how good it looks, which is a useful model for our adherence evaluation. No weights released.
- Comfy API is live (30 Sep). Its `comfy build init` records the ComfyUI version, nodes, models and packages, which could give K4 its environment section for free.
- ComfyUI 0.37+ sends an Idempotency-Key on partner-node calls, so test E4's double-billing worry there. 0.36/0.37 added native depth estimators (Marigold v2, MoGe 3), useful for adherence checks.
- Comfy Agent is open to all Comfy Cloud users (still beta). comfy-cli has an open bug that can write a parameter into the wrong field while reporting success.

## Implementation progress

- New scripts: validate-output.py (self-test 7/7), silent-failure-test.py, v1-repeat-runs.py, comfy-runner.py (tests 9/9). Lab note: [Experiment 003](../../experiments/2026-10-02-v1-validator-silent-failure-test/)
- ComfyUI accepts the same prompt_id twice, and /api/jobs then shows one job, so a duplicate is invisible. The runner's ledger has to prevent duplicates. /history also lists input videos as outputs; the runner now ignores them.
- Fixed along the way: the runner and its tests looked for outputs in the wrong folder (SaveVideo's prefix ends in a file name, not a folder).
- Not done: a real ComfyUI restart mid-job (only simulated), stall detection (the runner just polls), the spend ledger, K4, choosing M0 workflows 2 and 3. Unity wasn't used this run.

## Risks / blocked

- Validator blind spots: frozen stretches up to 25% of a clip, fades to black, plausible-but-wrong output (like the wrong checkpoint).
- Zero failures in 30 runs only covers this one workflow (95% upper bound about 10%). LTX, fp8 and 81-frame runs are untested.
- The wiki notes that MiniMax H3 is "barred in US" conflicts with Comfy selling local commercial licences. It's flagged as a minor conflict for review.
