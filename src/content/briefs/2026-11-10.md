That string is also in the agent's command line (the run prompt quotes it), so the test killed the agent. The test now kills the pid listening on port 8188. Closest published match to our blockout → video idea: VBench-2.0 78.2% vs 54.6% for the same generator without the draft. It does not say how the draft conditions the model, and reports no adherence-to-draft metric (ours would be new).
